**Interfaces:**
- Consumes: `docs/record/sim_hover_step_run{1,2,3}/{bag_analysis.json,drone_1_odom.csv}` (odom CSV header `t_s,x,y,z`; events have `name`, `axis`, `onset_s_from_bag_start`, `final_m`, optional `goal.goal_m`, `commanded_delta_m`, `moved_m`, `start_m`; run2/3 JSON has `time_scale` + `time_scale_source`, run1 has neither).
- Produces (used by Task 2 and the HTX-R1 page):
  - `step_events(events: list[dict]) -> list[tuple[str, dict]]` — `(axis, event)` for every event whose name matches `^step_([xz])(?:_\d+)?$`, axis order x then z, then by step index.
  - `run_time_scale(j: dict, override: float | None) -> tuple[float, bool]` — `(scale, estimated)`; `override` wins and sets `estimated=True`; else the JSON's `time_scale` when present and its `time_scale_source` does not start with `"assumed"`; else raises `ValueError(f"{run}: no time scale (pass --time-scale {run}=<x>)")`.
  - `relative_trace(odom: list[tuple], ev: dict, time_scale: float, window_s: float = 8.0) -> tuple[list[float], list[float]]` — `(t_vehicle, y)` with `t_vehicle = (t - onset) * time_scale` for `onset ≤ t ≤ onset + window_s`, `y = (p_axis - p0) * sign`, `p0` = `ev["start_m"]` if present else the first odom sample at/after onset, `sign = +1 if (ev.get("commanded_delta_m") or ev.get("moved_m") or 1.0) >= 0 else -1` (so every step reads as a +1 m command).
  - `overlay(runs: list[tuple[str, pathlib.Path]], scales: dict[str, float], labels: dict[str, str], out: pathlib.Path) -> pathlib.Path` — two axes (x steps left, z steps right): goal line at 1.0 m, shaded band 0.9–1.1 m, vertical dashed line at 3.0 s labelled "3 s gate", x-axis "time since step onset (PX4 vehicle s)", y-axis "position along the commanded axis, relative to onset (m)". One hue per run in the given order (dataviz skill: three distinct, colour-blind-safe hues; same hue for every step of a run; legend one entry per run, plus a direct label at each run's last sample); legend text `"{label} · {run} · n={steps} · scale {scale:.3f}"` + `" (est.)"` when estimated. Figure footer: `"Sim only. tools/hover_step_plot.py --overlay … ; onset/settle definitions in tools/hover_step_analysis.py"`. White background, dark-safe ink colours as in the existing `_style`.
  - CLI: `tools/hover_step_plot.py --overlay RUN [RUN…] [--time-scale RUN=X]… [--label RUN=TEXT]… -o PNG` where `RUN` is a run directory path (or a bare run name resolved to `docs/record/<name>/`); the key in `--time-scale`/`--label` is the directory's base name. `-o` required in overlay mode. Exit 0 on success, 2 on usage error or a `ValueError` from `run_time_scale` (message to stderr).

    def test_run_time_scale_prefers_override_and_marks_estimated(self):
        self.assertEqual(P.run_time_scale({"time_scale": 1.3329, "time_scale_source": "px4_arm_times.txt (sysid 2)"}, None), (1.3329, False))
        self.assertEqual(P.run_time_scale({"time_scale": 1.3329, "time_scale_source": "px4_arm_times.txt (sysid 2)"}, 1.336), (1.336, True))
        with self.assertRaises(ValueError): P.run_time_scale({"time_scale": 1.0, "time_scale_source": "assumed 1.0 (no px4_arm_times)"}, None)
